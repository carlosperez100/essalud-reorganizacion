# Planteamiento para la Reorganización de EsSalud

Propuesta técnica independiente elaborada con el **Modelo de Excelencia GEMSES** —
diagnóstico en 13 cifras verificadas con fuente primaria pública y planteamiento en 6 ejes,
cada uno con indicador, línea de base y responsable.

**Autor:** Mg. Carlos Pérez Pérez · Investigador RENACYT · ORCID 0000-0001-8425-1875

- **Portal:** https://carlosperez100.github.io/essalud-reorganizacion/
- **Documento completo (PDF):** [`docs/Planteamiento_Reorganizacion_EsSalud_CPP_v1.pdf`](docs/Planteamiento_Reorganizacion_EsSalud_CPP_v1.pdf)

Todas las cifras provienen de fuentes primarias públicas (Evaluación Presupuestal FONAFE,
PEI 2026-2030, ROF vigente, Libro Blanco 2019, estudios OIT, RENIPRESS, Censo INEI 2025)
citadas en el propio portal. Documento técnico independiente: no es una publicación oficial de EsSalud.
